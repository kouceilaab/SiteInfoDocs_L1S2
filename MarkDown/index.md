# Tim Berners-Lee

## Qui est Tim Berners-Lee ?

![Portrait de Tim Berners-Lee](../Images/portrait.jpg "Tim Berners-Lee, inventeur du Web")

**Sir Timothy John Berners-Lee**, né le **8 juin 1955** à Londres, est un informaticien britannique mondialement reconnu pour avoir inventé le **World Wide Web** en 1989. Son travail a changé la façon dont l'humanité communique, apprend, travaille et se divertit.

Il importe de distinguer deux choses souvent confondues : **Internet** est le réseau mondial de machines interconnectées, tandis que le **Web** est un système de documents liés entre eux accessibles via Internet. C'est ce second système que Berners-Lee a inventé.

Il a fait le choix remarquable de **ne jamais breveter** son invention, la rendant entièrement libre et gratuite pour toute l'humanité.

> « Le Web est plus une création sociale qu'une technique. Je l'ai conçu pour un effet social — pour aider les gens à travailler ensemble. » — Tim Berners-Lee

## Chronologie

Voici les grandes étapes de la vie et de l'œuvre de Tim Berners-Lee :

| Année | Événement |
|:------|:----------|
| 1955 | Naissance à Londres, Angleterre |
| 1976 | Diplômé en physique à l'Université d'Oxford |
| 1980 | Premier séjour au CERN, développe ENQUIRE |
| 1989 | Propose le projet World Wide Web au CERN |
| 1990 | Premier serveur et premier navigateur Web |
| 1991 | Mise en ligne du premier site web : info.cern.ch |
| 1994 | Fonde le W3C au MIT |
| 2004 | Anobli chevalier par la reine Elizabeth II |
| 2009 | Fonde la World Wide Web Foundation |
| 2016 | Reçoit le prix Turing, le Nobel de l'informatique |
| 2018 | Lance le projet SOLID pour décentraliser le Web |

**Chiffre clé :** Le Web compte aujourd'hui plus de 1,9 milliard de sites et 5 milliards d'utilisateurs dans le monde.
